What This Slice Represents

EmbeddingsTokens become numeric feature vectors, not dictionary definitions.
AttentionThe current position copies useful context from earlier positions.
MLPA feature mixer boosts patterns that the model learned during training.
LogitsCandidate next tokens are scored before probabilities exist.
TemperatureHigher values flatten probabilities and make odd tokens easier to pick.
LoopThe chosen token is appended, then the whole decoder slice runs again.
